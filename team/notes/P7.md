## What was done
- **Ruff configured** in `pyproject.toml`: line length 120 (the code is written to about that width), Python 3.12, `verification/` and `sources/` excluded (they are never edited by contributors, `AGENTS.md`). Lint rules: `E4`, `E7`, `E9`, `F` (pyflakes), `W`, `B` (bugbear), with `B905` (`zip(strict=)`) ignored. **Labelled choice:** errors and likely bugs, not taste. Ruff 0.17's default set reports 134 items on the repository, most of them style; this set reports 14, of which 10 were `B905` in tests.
- **Four lint fixes**, none changing behaviour: unused imports in `gates/t9.py` (`make_law`), `engine/tests/test_runner.py` (`SCALED`), `scenarios/D21/run.py` (`Path`), and the name `l` in `tools/check_architecture.py`. `ruff check .`: **All checks passed**.
- **Pinned** `ruff==0.17.5` in the dev extras (`test_pins.py` requires exact pins).
- **CI:** a new job `lint` in `.github/workflows/verify.yml` installs the ruff pinned in `pyproject.toml` (read from the file, so there is one pin only) and runs `ruff check .`.
- **Format: configured, not applied.** A first `ruff format .` would rewrite 36 files (about 2,500 diff lines), far beyond the 400-line limit of `TEAM.md`, section 7, and in conflict with every open pull request. Proposed as decision **D25** (written D23 on the branch): the maintainer runs it once, alone, when no pull request is open; then CI adds `ruff format --check .`.
- **Dev container (fault found):** its `postCreateCommand` installed `requirements.txt` and unpinned `pytest pytest-cov ruff jsonschema`, but **not the engine itself**, so `pytest` in a new Codespace would fail to import `cosmicmass`. Now: `pip install -r requirements.txt && pip install -e ".[dev]"`, which installs the engine and the pinned dev tools.

## Check of "a new Codespace runs pytest with no manual steps"
Docker is not available on this machine, so the container itself was not built. Instead, a clean clone of the branch in a new, empty Python 3.12 environment ran exactly the container's `postCreateCommand`, then `pytest` and `ruff check .` with no other step: **206 passed, 1 deselected; All checks passed**. What this does not check: the image `mcr.microsoft.com/devcontainers/python:3.12` itself and the VS Code extensions. A first real Codespace should confirm it.
